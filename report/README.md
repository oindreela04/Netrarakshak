# IEEE-format project report

- `netrarakshak_ieee.pdf` — compiled paper (5 pages, IEEE conference two-column layout)
- `netrarakshak_ieee.tex` + `figures/` — LaTeX source

The source uses the official `IEEEtran` class automatically when it is installed (Overleaf, MiKTeX, full TeX Live),
and otherwise falls back to an equivalent two-column layout. To edit on Overleaf: New Project → Upload Project → upload
this folder as a zip. Check the author name and affiliation in the `\author{...}` block before submitting.
All metrics in the paper are copied from the model card produced by the training pipeline.
