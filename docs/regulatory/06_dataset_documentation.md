# Dataset documentation

See `../datasets.md` for candidate sources and licensing. For every training run the model card records:
dataset name, licence/terms as accepted by the operator, label format, image count, split sizes, grade counts per
split, split method and whether data is synthetic. Split membership CSVs are saved in the run folder.

Datasheet items to complete for each real dataset before use: provenance and collection protocol; camera models;
population demographics; inclusion/exclusion; labelling protocol and grader qualifications; inter-grader agreement;
known label noise; de-identification method; consent basis; retention and access controls.
